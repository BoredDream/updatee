# 问题二核对与修改说明

以《简洁_问题一修订.md》为底稿，形成《简洁_问题一二修订.md》。问题一正文及问题三至四正文逐字保留；本次改写问题二完整章节，并补充公共符号说明及相关预处理表述。原稿、模型代码和附件5工作簿均未覆盖。

## 主要差异及处理

| 原文问题 | 修改结果 |
|---|---|
| 预测公式缺少预测标记，实际值与中心预测混用 | 明确定义目标日期、信息截止日期和带预测标记的净负荷 |
| 原残差公式两项看似都为实际净负荷 | 改为145段实际路径减去对应历史截止日下的预测路径 |
| 未说明历史残差的权重口径 | 明确采用当前所选权重重算历史预测，区别于历史发布误差存档 |
| 情景概率使用πω，与电价符号π冲突 | 统一使用ϖω |
| 同时混用G、C、D、E、U、S、N及d、t | 统一为χ、κ、δ、ζ、υ、σ、ξ及ν、τ |
| 145段窗口与144段自然日混用，末端状态含义不清 | 另设规划索引h及波浪号，区分日末24:00和规划末端次日00:10 |
| 购电映射写成同名变量的自指分段式 | 明确首段固定、其余144项共同决策及末项跨日承诺 |
| 情景数容易被误解为固定7、14或30 | 说明7、14是候选残差窗口，条数取有效样本，无样本时退化为单中心情景 |
| 历史能量评分表述过简 | 补充能量评分公式和历史分布比较范围，不将其冒充每个历史时刻的已部署检验 |
| 将情景充放电平均量与实际动作混为一谈 | 区分平均参考、抵消共同动作、可行性裁剪及实际供需补救 |
| 终端价值仍使用v，目标与实际费用界限不够清楚 | 统一λ，区分优化目标和自然日实际购电费；首段常数只从优化目标省略 |
| 部分结果仅有概述及图片占位，题目指定表格不完整 | 从当前复算输出生成四日期购电、充放电、紧急购电和敏感性表 |
| 原文称明细SHA256相同，缺少本次可核对的历史明细 | 删除该强断言，改为当前全年复算与现存Excel及现有验收脚本的一致性证据 |
| 原公式含错误的转义及外层方括号 | 重写为可编辑的Markdown数学公式；问题二编号统一为6.2 |
